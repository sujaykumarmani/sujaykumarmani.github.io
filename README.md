# Sujay Kumar Mani — Finance Portfolio

GitHub Pages-ready portfolio focused on core accounting, end-to-end process ownership, financial analysis, systems adaptability and practical process improvement.

## Upload
Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder to the root of `sujaykumarmani.github.io`. Commit to `main`. In Settings → Pages choose Deploy from a branch, `main`, `/ (root)`, then Save.

The resume PDF is included under `assets/`. The site describes O2C as process understanding/adaptability and does not claim deep end-to-end O2C ownership. Quantified achievements are identified as figures stated in the resume.


## Typography
The entire website uses a consistent Arial/Helvetica sans-serif font stack. External decorative font imports have been removed.
